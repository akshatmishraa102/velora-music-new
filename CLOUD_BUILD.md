# GitHub Actions build

1. Push this project to a GitHub repository.
2. Open Actions.
3. Select `Build Velora Music APK`.
4. Use `Run workflow`, or push to `main`.
5. When green, open the run and download the `Velora-Music-debug-apk` artifact.

The workflow uses:
- JDK 17
- Android SDK 35
- Gradle 8.11.1
- Android Gradle Plugin 8.7.3
