# Velora Music

Android music player project.

## Identity
- App name: Velora Music
- Application ID: com.veloramusic
- Namespace: com.veloramusic
- Minimum Android: 6.0 (API 23)

## Included in this clean base
- Local device music scanning
- Online stream URL import for audio you own or are licensed to stream
- Background playback with Media3 MediaSession
- Home, Search, Library and Customise screens
- Lightweight programmatic UI
- Accent theme selection
- Animation intensity control scaffold
- GitHub Actions APK build

## Build on GitHub
The included workflow installs Gradle 8.11.1 and builds with JDK 17.

No Gradle wrapper is required.

## Important
This project does not include an unlicensed commercial music catalogue.
